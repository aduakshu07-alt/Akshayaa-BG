# Online Course Reservation System

## Project Description
A Java and MySQL application that allows students to register, browse courses, enroll in courses, record demo payments, and track learning progress.

## Features
- Student registration and login
- Browse available courses
- Course enrollment
- Payment record management
- Learning progress tracking

## Technologies Used
- Java
- JDBC
- MySQL
- SQL

## How to Run
1. Install Java JDK and MySQL Server.
2. Execute `database.sql` in MySQL Workbench.
3. Configure your MySQL username and password in the Java source code.
4. Add the MySQL Connector/J JAR to your classpath.
5. Compile and run `OnlineCourseSystem.java`.

## Note
The payment feature is a simulation and does not process real payments.
